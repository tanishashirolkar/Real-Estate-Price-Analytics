# 🏡 Real Estate Price Analytics

**End-to-End Data Analytics Project using Python and Power BI**

## 📌 Project Overview

This project analyzes the King County House Sales Dataset to explore real estate prices, understand relationships between property features, and identify location-based pricing patterns.

The project primarily focuses on **Python-based data analysis and Exploratory Data Analysis (EDA)** using Pandas, NumPy, Matplotlib, and Seaborn. Power BI is used to present the findings through interactive dashboards.

## 🎯 Project Objectives

- Load, inspect, and clean housing data using Python.
- Perform data manipulation and preprocessing using Pandas and NumPy.
- Conduct Exploratory Data Analysis to identify patterns and relationships.
- Visualize housing prices and property features using Matplotlib and Seaborn.
- Analyze price variations across ZIP codes and over time.
- Present key findings through Power BI dashboards.

## 🛠️ Skills & Tools Used

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Data Analytics:** Data Cleaning, Data Preprocessing, Exploratory Data Analysis (EDA), Statistical Analysis, Correlation Analysis, Outlier Analysis, Trend Analysis
- **Tools:** Google Colab, Jupyter Notebook, Power BI, GitHub

## 📂 Dataset

**Dataset Name:** King County House Sales Dataset

## 🔍 Project Workflow

### 1️⃣ Data Loading & Understanding

- Loaded the dataset into Python using Pandas.
- Examined the dataset dimensions, column names, and data types.
- Inspected numerical and categorical columns.
- Used descriptive statistics to understand the data.

### 2️⃣ Data Cleaning & Preprocessing

- Checked for missing values in the dataset.
- Handled missing values in relevant columns.
- Converted the date column to the appropriate date format.
- Prepared the data for further analysis.

### 3️⃣ Exploratory Data Analysis (EDA)

Performed EDA using Pandas, NumPy, Matplotlib, and Seaborn to explore housing prices and property characteristics.

**Key EDA techniques and visualizations:**

- **Histograms:** Examined the distribution of house prices and numerical features.
- **Scatter Plots:** Explored the relationship between living area and house prices.
- **Box Plots:** Analyzed price variation and potential outliers.
- **Correlation Heatmaps:** Visualized correlations between numerical variables.
- **Bar Charts:** Compared housing prices across different ZIP codes.
- **Line Charts:** Examined average house price trends over time.

### 4️⃣ Price & Location Analysis

- Analyzed the relationship between living area and house prices.
- Compared house prices across different ZIP codes.
- Explored average house price trends over time.
- Examined price per square foot to compare properties relative to their living area.
- Used visualizations to identify patterns and differences in the housing market.

## 💡 Key Insights

- Explored how living area relates to house prices.
- Identified differences in house prices across ZIP codes.
- Examined variations in house price distributions.
- Analyzed changes in average house prices over time.
- Investigated price per square foot to compare property values.

*The analysis is exploratory and describes patterns in the dataset; it does not establish causation or predict future house prices.*

## 📈 Business Recommendations

- Consider both property size and location when comparing house prices.
- Use ZIP code-level price comparisons to understand differences between locations.
- Compare price per square foot alongside total property price.
- Use historical price trends as context when reviewing housing market patterns.
