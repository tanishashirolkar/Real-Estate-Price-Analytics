# Real Estate Price Analytics | Power BI

An interactive real estate analytics project built using Power BI to explore housing prices, geographical price variations, and the relationship between living area and house prices.

## 📌 Project Overview

This project analyzes the King County house sales dataset to understand residential property prices and identify patterns across ZIP codes and months. The dataset is cleaned and transformed using Power Query, and the results are presented through interactive Power BI dashboards.

## 🎯 Project Objectives

- Analyze key housing market indicators.
- Compare average and median house prices across ZIP codes.
- Explore monthly variations in average house prices.
- Examine the relationship between living area and house prices.
- Present housing market insights through interactive visualizations.

## 🔄 Project Workflow

The project follows a structured data analytics workflow:

1. **Data Collection** — Loaded the King County house sales dataset in CSV format.
2. **Data Cleaning** — Identified missing values and handled them using Power Query.
3. **Data Transformation** — Changed data types, prepared relevant columns, and organized the dataset for analysis.
4. **Data Analysis** — Examined housing prices and property characteristics using aggregations such as average and median.
5. **Data Visualization** — Created KPI cards, bar charts, a line chart, and a scatter plot in Power BI.
6. **Insight Generation** — Compared prices across ZIP codes, explored monthly price patterns, and examined the relationship between living area and sale price.
7. **Dashboard Development** — Arranged the visualizations into two report pages to present the findings clearly.

## 🧰 Tools & Technologies

- **Power BI Desktop** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **CSV Dataset** — Source housing sales data

## 🔍 Key Findings

- **21,613** housing records are included in the dataset.
- The average house price is approximately **$540.09K**.
- The median house price is approximately **$450K**.
- ZIP code **98039** has the highest median house price among the ZIP codes displayed in the dashboard.
- The scatter plot indicates a general positive relationship between living area and house price, although some properties are outliers.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Open `Real_Estate_Project_Dashborad.pbix`.
4. If Power BI requests the data source location, select the downloaded CSV file.
5. Refresh the data if required.
6. Explore both dashboard pages and interact with the visualizations.
